# Claude Architecture Research

Research project for experimenting with the architecture of Claude Code
instructions using CleanArchitectureTemplate V2 as the baseline.

## Versions

- `templates/v2-baseline` — frozen baseline.
- `templates/v3` — experimental version.

## Research artifacts

- `research/` — hypothesis, requirements and observations.
- `prompts/` — prompts used to generate and modify V3.
- `benchmarks/` — behavioral tests.
- `results/` — experiment results.
